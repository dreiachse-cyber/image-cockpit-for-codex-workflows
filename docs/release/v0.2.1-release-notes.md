# v0.2.1 Release Notes

Status: owner-approved and prepared for tag `v0.2.1`
Target: approachable Prompt Examples and a broader pixel-art character catalog after v0.1.8

Image Cockpit for Codex Workflows v0.2.1 makes the first generation step intentionally lighter while expanding the detailed catalog with owner-reviewed animals, chibi characters, and beastfolk.

## Highlights

### Start broad, then add your own details

- Prompt Examples now opens with nine short starting points: Elderly Man, Elderly Woman, Man, Woman, Girl, Boy, Cat, Dog, and Monster.
- The first layer uses text and neutral icons instead of preview images so it does not anchor the user to a finished visual answer.
- `Start with this` updates only the main prompt and preserves the user's Negative Prompt and Generation Notes.
- `View concrete examples` opens a related subset, while `View all concrete examples` keeps the complete detailed catalog available.
- The existing 137 detailed prompts, preview images, category filters, Copy Prompt action, and Use Prompt action remain intact one layer below.

### 30 new detailed presets

- Animals: dog, cat, red panda, fox, rabbit, giant panda, lion, tiger, wolf, and brown bear.
- Chibi Boys: five distinct hair, palette, outfit, and role combinations.
- Chibi Girls: five distinct hair, palette, outfit, and role combinations.
- Beastfolk: wolf, cat, fox, rabbit, tiger, lion, bear, red panda, deer, and goat.
- The detailed Prompt Examples catalog now contains 137 entries in total.

### Production-oriented preview assets

- The 30 new previews were generated as individual assets and accepted by the owner before release.
- Every final preview is a 1254 x 1254 RGBA PNG with transparent corners, at least 32 px subject padding, no edge contact, no disconnected tiny alpha debris, and alpha bounds centered within 1 px.
- Machine-readable dimensions, alpha bounds, padding, component checks, file sizes, and SHA-256 values are recorded in `docs/qa/prompt-examples/animal-chibi-beastfolk-presets/asset-qc.json`.
- The 30 PNG files add approximately 16.1 MiB to the repository.

### Accessibility, localization, and documentation

- The new layer UI is localized for all 15 supported interface languages.
- Focus trapping, Escape handling, related-layer back navigation, and focus return to the originating control are covered.
- Narrow layouts stack the short-prompt actions without horizontal overflow.
- README workflow screenshots were refreshed, and screenshot capture no longer reads an unrelated local Supervisor instance.

## Prompt-length guidance

Shorter prompts are designed to reduce the psychological cost of editing and leave more room for exploration. They do not guarantee faster image generation; resolution, quality settings, model-side work, and service conditions can matter more than prompt length.

## Local-First Boundary

The app still does not call OpenAI APIs directly and does not require an API key. It writes local handoff files for Codex, the user, or another local workflow to process.

No API keys, tokens, model weights, generated handoff folders, raw ImageGen working files, or license-unclear assets are included in the repository.

Release verification targets:

- all 30 new preview assets pass the committed mechanical QA record.
- the simple layer contains exactly 9 prompts and the detailed layer contains exactly 137 examples.
- English and Japanese titles and short prompts match their stable IDs.

- release audit covers these notes and `docs/qa/v0.2.1-release-prep.md`.

## Known Limitations

- Short starting prompts deliberately leave appearance choices to the generation model, so outputs may vary more than the detailed examples.
- Generation speed is not guaranteed to improve solely because the visible prompt is shorter.
- Preview assets are optimized for transparent pixel-art source use, but downstream animation quality still depends on the selected model and motion request.
