# v0.1.7 Release Notes

Status: approved and prepared for tag `v0.1.7`
Target: selectable single-direction animation generation and Experimental extended frame budgets after v0.1.6

Image Cockpit for Codex Workflows v0.1.7 adds a lower-output single-direction path and Experimental 16-frame and 20-frame animation budgets while preserving the established five-direction, 8-frame, and Best-profile defaults.

Feature scope is the branch range from `v0.1.6` through `codex/selectable-single-animation-direction`, including the side-only foundation, the extended frame-budget update, the final selectable-direction implementation, and this v0.1.7 release-prep update.

## Highlights

### Selectable single-direction animation generation

- Added `1 direction` alongside the existing `5 directions` and `3 directions` presets.
- The initial side-only implementation was superseded before release by a selector for front, front three-quarter, side, back three-quarter, or back.
- The overall default remains `5 directions`; side remains the default when `1 direction` is selected.
- The chosen direction is preserved through prompts, tournament jobs, previews, history restoration, manifests, exports, and Animation Pack v2 reuse.
- Invalid imported single-direction values safely fall back to side.
- The selector remains keyboard accessible, uses 48px minimum targets, and fits without horizontal overflow at 390px width.

### Experimental 16f and 20f budgets

- Animation Generation now supports 4f / 6f / 8f / 12f / 16f / 20f while keeping 8f as the default.
- Existing 4f / 6f / 8f / 12f budgets remain Stable; only 16f and 20f are labeled Experimental.
- Raw per-direction contracts use 4x4 cells for 16f and 4x5 cells for 20f.
- Final sheets continue to use one row per requested direction and one column per animation frame.
- At the standard 256px cell size, a single-direction 20f sheet is 5120x256px, while a five-direction 20f sheet can reach 5120x1280px.
- Direction, Motion Recipe, frame count, raw grid, timeline, and Animation Pack metadata survive export and re-import without falling back to 8f.
- Effect Animation frame choices are unchanged.

## Generation defaults and performance guidance

- v0.1.7 does not switch animation generation to Fast. Best remains the fresh-session default and compares three candidates; Fast remains an optional one-candidate mode.
- Motion Pilot Tournament remains Experimental, Best-only, default OFF, and unavailable for single-direction generation.
- Motion Pilot is separate from the Best profile itself: selecting Best does not enable Motion Pilot automatically.
- A real five-direction, 20f, Best-profile tournament completed successfully in 58 minutes 24 seconds in the current Windows/local Codex environment. This is one observed run, not a duration guarantee.
- Five-direction 20f generation is particularly heavy because each Best candidate contains 100 frame cells and all three candidates are compared.
- Runtime still depends on the local Codex/imagegen environment, model-side behavior, network availability, retries, and quality checks.

## Local-First Boundary

The app still does not call OpenAI APIs directly and does not require an API key. It writes local handoff files for Codex, the user, or another local workflow to process.

No model weights, API keys, tokens, generated handoff folders, or license-unclear sample assets are included in the repository.

## Known Limitations

- 16f and 20f remain Experimental because they take longer, create larger files, and may exceed texture limits in some engines.
- Increasing the frame count does not change FPS automatically; at the same FPS, additional frames lengthen playback unless timing is adjusted in the Animation Timeline.
- Motion Pilot remains opt-in because its earlier benchmark included fallback-heavy cases that took 2.86-3.30 times the Fast comparison path.
- Generated image quality and completion time remain dependent on the available local generation environment.
- Heavy generated outputs and temporary browser-review artifacts remain local-only.
