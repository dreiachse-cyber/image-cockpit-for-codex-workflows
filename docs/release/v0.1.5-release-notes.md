# v0.1.5 Release Notes

Status: prepared for tag `v0.1.5`
Target: Monster Girl Chibi prompt examples, source previews, and animation-generation QA after v0.1.4

Image Cockpit for Codex Workflows v0.1.5 expands the prompt-example catalog with a focused set of cute two-head-tall monster girl source characters. The release is meant to make Animation Generation easier to test and more approachable for game-asset workflows.

Feature scope is the main branch range from `v0.1.4` through the `codex/monster-girl-prompt-animation-batch` branch, plus this v0.1.5 release-prep update.

## Highlights

- Added a new `Monster Girl Chibi` / `モンスター娘ちび` prompt example category.
- Added 20 family-friendly two-head-tall monster girl source prompts.
- Added 20 generated transparent PNG preview assets for those prompts.
- Verified the prompt modal now exposes 107 prompt example cards.
- Completed the MG01-MG20 animation batch: front idle, side idle, side run, side walk, and side attack.
- Preserved action metadata when publishing verified direction-split tournament winners.
- Relaxed direction-split interior-alpha rejection so usable compact attack poses can pass with warnings instead of false failure.

## Animation QA

The MG01-MG20 batch was run through Image Cockpit as a real animation-generation stress test. Each character has accepted results for:

- front idle
- side idle
- side run
- side walk
- side attack

The batch uses 100 accepted animation slots. Front idle and side idle share one five-direction idle sheet per character, so the accepted set corresponds to 80 unique generated animation jobs.

The public repository includes the lightweight prompt previews and release QA notes. Heavy local comparison sheets, generated outbox files, and temporary review galleries are intentionally not included in the release payload.

## Local-First Boundary

The app still does not call OpenAI APIs directly and does not require an API key. It writes local handoff files for Codex, the user, or another local workflow to process.

No model weights, API keys, tokens, generated handoff folders, or license-unclear sample assets are included in the repository.

## Known Limitations

- The 20x5 animation batch is QA evidence and a prompt-catalog stress test; it is not shipped as a built-in official animation library.
- Generated image quality can still vary by local Codex/imagegen availability and model-side behavior.
- Large local QA contact sheets and temporary HTML galleries remain local-only to avoid inflating the public repository.
