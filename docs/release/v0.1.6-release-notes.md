# v0.1.6 Release Notes

Status: approved and prepared for tag `v0.1.6`
Target: animation generation efficiency, repertoire, quality tooling, and workflow readability after v0.1.5

Image Cockpit for Codex Workflows v0.1.6 turns the animation workflow into a more complete local production loop. It improves candidate generation and recovery, expands motion and VFX coverage, adds review/edit/export tooling, and makes the main workflows substantially easier to read and operate.

Feature scope is the main branch range from `v0.1.5` through the `codex/animation-uplift-sequence` branch, including the preceding animation review-fix takeover commits and this v0.1.6 release-prep update.

## Highlights

### Faster, recoverable candidate generation

- Quality Gate v2 records shadow metrics for raw/normalized comparison, correction amount, identity, palette, silhouette, action profile, phase, and loop seam while preserving the existing hard gate.
- Fast / Balanced / Best adaptive tournaments support versioned persistence, idempotent resume, and recovery under the same job ID.
- Direction Repair regenerates only the rejected direction and preserves the accepted directions byte-for-byte.
- Batch Matrix runs two source images by two motions while a global controller limits real generation to three concurrent runners.

### Broader animation repertoire and stronger prompts

- Motion Recipe v1 and its versioned compiler connect motion intent, prompt construction, QA contracts, history, manifests, and export metadata.
- The catalog now provides 22 recipes across six body topologies, nine structured modifiers, and 4 / 6 / 8 / 12-frame budgets.
- Legacy, v0, and unknown recipe payloads retain explicit fallback behavior instead of silently losing animation intent.

### Review, edit, and export without regenerating frames

- Animation Timeline Review/Edit supports per-frame duration, Hold, Duplicate, Reverse, Loop, One-shot, Ping-pong, events, Pivot, Anchor, Socket, Hitbox, Hurtbox, Undo/Redo, and recipe reset.
- Animation Pack v2 adds v1 migration, lossless round-trip metadata, and Generic / Godot / Phaser / Aseprite / Unity-compatible common metadata.
- Animation Review Cockpit synchronizes A/B/C candidates by direction, frame, and speed; provides eight review axes, Direction x Frame QC matrices, Raw/Normalized/Adjacent diff modes, production overlays, and persisted human review decisions.

### VFX composition and repertoire

- VFX Composite Stage combines separate character and effect layers with six sockets, five events, front/back depth, Normal/Additive/Screen blend modes, transform/timing controls, preview backgrounds, and overlays.
- The effect repertoire includes six additional VFX categories alongside the original five categories.
- Combined GIF, APNG, sprite sheet, separate-layer files, manifest, and Generic / Godot / Phaser Composite Pack exports can be re-imported for continued review.

### Clearer, more accessible workflows

- The four primary workflows now occupy the top of the left column in a large 2x2 control.
- Animation Generation keeps preset, direction, and generate as its primary path; topology, frame budget, modifier, profile, Motion Pilot, Batch Matrix, comparison, repair, and history are optional modal tools.
- Effect Animation keeps effect selection and generation primary; category/variation, style, palette, sheet, prompt, preview, and VFX Composite Stage are focused optional tools.
- Base typography is 16px, primary targets are 48-60px high, modal keyboard/focus behavior is explicit, and 390px layouts avoid horizontal overflow.
- Normal and Effect result cards keep enlarged text, thumbnails, and metadata inside stable card bounds without narrowing the center preview.

### Reliability and repository health

- Production imagegen flows reject mock-runner output while real terminal/manual jobs remain visible in Cockpit logs.
- The default standard animation flow uses three parallel candidates and offers balanced five/three-direction controls without the low-value one-direction mode.
- UI smoke coverage now stabilizes queued fourth-job and Effect-completion timing.
- Heavy local QA binaries remain untracked and bundled sample PNGs are optimized to keep the public repository lean.

## Experimental Motion Pilot decision

Motion Pilot Tournament remains Experimental, Best-only, and default OFF. One benchmark set expanded successfully, while two sets required fallback and took 2.86-3.30 times the Fast path. The workflow is available for deliberate comparison, but it is not presented as the standard efficiency path in v0.1.6.

## Local-First Boundary

The app still does not call OpenAI APIs directly and does not require an API key. It writes local handoff files for Codex, the user, or another local workflow to process.

No model weights, API keys, tokens, generated handoff folders, or license-unclear sample assets are included in the repository.

## Known Limitations

- Quality Gate v2 metrics are shadow evidence in this release; they do not replace the existing hard acceptance gate.
- Motion Pilot remains opt-in because its final benchmark did not establish a reliable speed advantage.
- Generated image quality and completion time still depend on local Codex/imagegen availability and model-side behavior.
- Heavy comparison sheets, generated outbox files, and temporary browser-review artifacts remain local-only.
