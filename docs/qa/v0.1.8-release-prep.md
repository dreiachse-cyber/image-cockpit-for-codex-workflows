## First Qualified Wins contract

- Applies only to non-Pilot Best tournaments using `smart-race`.
- Requires exactly one terminal candidate while both other Best candidates remain running.
- Requires every requested direction to be verified.
- Requires zero quality warnings because the current warning count has no severity classification.
- Requires score `>= 3300`.
- Requires identity score `>= 85`.
- Requires `shadowWouldBlock: false`.
- Persists decision mode `first-qualified`.
- Cancels both remaining runners after winner publication.
- Rejects the one-candidate decision if another candidate becomes terminal, then falls back to the existing two-candidate Smart Race or full three-candidate comparison.

## Integrated queue and admission protections

- Restored queued tournaments remain monitor-only until explicitly allowed in the current session.
- Generate uses a synchronous in-flight lock.
- Server registration deduplicates unfinished semantic matches under the global registration lock.
- Register-and-start checks capacity before creating a new tournament manifest, so rejected admission leaves no phantom queue entry.
- Initial Best admission remains all-or-nothing across three global runner slots.
- Direction Repair and adaptive Balanced starts remain fail-closed under their existing guards.
