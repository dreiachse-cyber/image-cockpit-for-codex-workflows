## Release QA finding

The first v0.2.1 screenshot pass exposed a timing window where the Image Editing screenshot could be captured while Cockpit health still displayed `Checking`. The capture helper now waits for `.cockpit-health-panel.state-ok` immediately before every screenshot. A complete recapture passed, and all four images were visually reviewed with `v0.2.1` and Cockpit OK visible.
