## Included Feature Evidence

- `docs/qa/single-horizontal-direction.md` records the original one-row side-only foundation. It is retained as implementation history, not the final selectable-direction contract.
- `docs/qa/experimental-16-20-frame-animation.md` covers the Experimental 16f=`4x4` and 20f=`4x5` raw contracts, 1/3/5-direction final sheets, Pack metadata, warnings, and maximum-path browser checks.
- `docs/qa/selectable-single-animation-direction.md` records the final front / front three-quarter / side / back three-quarter / back selector, side default, arbitrary single-direction jobs, history restoration, manifest/export behavior, accessibility, and responsive coverage.
- The overall defaults remain 5 directions, 8f, and Best. Fast stays optional rather than becoming the release default.
- Motion Pilot Tournament remains Experimental / Best-only / default OFF and is unavailable for single-direction generation.
- A real five-direction, 20f, Best-profile tournament completed in 58 minutes 24 seconds in the current local environment; the duration is evidence from one run, not a performance guarantee.
- Direction, Motion Recipe, frame count, raw grid, timeline, and Animation Pack v2 metadata remain stable across history, manifest, export, and re-import paths.
- Release validation hardened the full UI smoke navigation wait and made the queued fourth-job click atomic with observing the three-runner capacity state, eliminating two timing-only failures found during release prep.
- `codex-handoff/`, generated outbox files, large local QA binaries, and temporary review artifacts are intentionally not included in the release payload.
