## Included Feature Evidence

- Quality Gate v2 shadow metrics preserve the existing hard gate while recording raw/normalized, correction, identity, palette, silhouette, action-profile, phase, and loop evidence.
- Fast / Balanced / Best tournaments persist and resume under the same job ID; Direction Repair preserves unaffected direction hashes; Batch Matrix observes the global three-runner limit.
- Motion Recipe v1 covers 22 recipes, six body topologies, nine modifiers, and 4 / 6 / 8 / 12-frame budgets.
- Animation Timeline and Animation Pack v2 preserve review edits and metadata through export/re-import round trips.
- Animation Review Cockpit provides synchronized A/B/C comparison, eight review axes, Direction x Frame QC, diff/overlay tools, and persisted human decisions.
- VFX Composite Stage supports separate character/effect layers, sockets/events, blend/depth/transform/timing controls, expanded effect categories, combined exports, and pack re-import.
- Motion Pilot Tournament remains Experimental / Best-only / default OFF after final benchmark results showed fallback-heavy cases at 2.86-3.30 times Fast duration.
- Animation Generation and Effect Animation use minimal primary left-column controls with optional modals, while the four main workflow switches stay at the top.
- 16px base typography, 48-60px primary targets, modal focus/Escape/return behavior, 390x844 responsive layout, and bounded result cards were verified in real browser review.
- `codex-handoff/`, generated outbox files, large local QA binaries, and temporary review artifacts are intentionally not included in the release payload.
