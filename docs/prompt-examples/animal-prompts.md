# Animal Pixel-Art Prompt Examples

作成日: 2026-07-27

このファイルは、ピクセルアート生成の「動物」向けprompt例をまとめた参照用メモです。
1枚につき1体だけを全身・中央配置で描き、アニメーション素材へ展開しやすい条件を揃えています。

## 共通方針

- 1枚につき1体の動物のみ生成する。
- 耳、鼻先、胴体、四肢、足先、尻尾まで全身を画像内に収める。
- 中央配置の自然なidle poseとし、animation-readyな読みやすいシルエットにする。
- 背景は透明を優先し、不可なら完全な単色クロマキー背景を使う。

## Common Negative Prompt

```text
blur, text, watermark, logo, cropped head, cropped ears, cropped paws, cropped feet, cropped tail, cut off body, extra limbs, missing limbs, duplicate animal, multiple animals, human body, humanoid pose, clothing, collar text, scenery, detailed background, floor shadow, photorealistic, 3d render, vector art
```

## Animal Prompts

### 01. Loyal Dog / 犬

```text
Create exactly one animal only as a single full-body pixel-art asset: a loyal small Shiba-like mixed-breed dog with warm golden-brown and cream fur, perked ears, dark nose, bright attentive eyes, sturdy paws, a curled fluffy tail, and a simple blue collar with no text. Use believable four-legged canine anatomy, a friendly alert expression, and a centered front three-quarter idle stance with all four paws visible, clear ground contact, a readable silhouette, and animation-ready limb separation. Use transparent background preferred, crisp 32-bit fantasy RPG pixel-art rendering, no clothing, no collar text, no scenery, no readable text, no logo, and no watermark. Keep the entire ears, muzzle, body, legs, paws, and tail fully inside the image with comfortable transparent padding. If transparency is unavailable, use a perfectly flat solid #00ff00 chroma-key background with no shadows, gradients, texture, floor plane, or lighting variation.
```
