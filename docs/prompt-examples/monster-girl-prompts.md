# Monster Girl Chibi Pixel-Art Prompt Examples

Created: 2026-07-02

This catalog adds cute two-head-tall monster girl source characters for Image Cockpit generation and follow-up animation testing.
Each prompt targets one full-body, family-friendly chibi character that can later be used as the source image for front idle, side idle, side run, side walk, and side attack animation generation.

## Common Negative Prompt

```text
blur, text, watermark, logo, cropped head, cropped feet, cut off body, extra limbs, duplicate character, duplicate face, scenery, detailed background, floor shadow, photorealistic, 3d render, vector art, disturbing horror content, serious realistic proportions, tall realistic proportions, model-like posing, exaggerated body proportions, overdesigned costume noise, busy silhouette
```
