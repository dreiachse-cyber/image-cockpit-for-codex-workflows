# Chibi Boy Pixel-Art Prompt Examples

作成日: 2026-07-27

このファイルは、外見、髪型、肌色、服装が明確に異なる「デフォルメ男の子」向けprompt例をまとめた参照用メモです。
2頭身の全身・中央配置を基本とし、アニメーション素材へ展開しやすい条件を揃えています。

## 共通方針

- 1枚につき1人のデフォルメ男の子のみ生成する。
- 頭、髪、手、小物、服の裾、足先まで全身を画像内に収める。
- 2頭身の中央idle poseとし、animation-readyな手足の分離と読みやすいシルエットを保つ。
- 背景は透明を優先し、不可なら完全な単色クロマキー背景を使う。

## Common Negative Prompt

```text
blur, text, watermark, logo, cropped head, cropped hair, cropped hands, cropped feet, cut off body, extra limbs, missing limbs, malformed hands, duplicate character, multiple characters, adult proportions, realistic anatomy, scenery, detailed background, floor shadow, photorealistic, 3d render, vector art
```

## Chibi Boy Prompts

### 01. Copper-Haired Scout / 赤毛の斥候少年

```text
Create exactly one character only as a single full-body two-head-tall chibi pixel-art boy asset: a fair-skinned boy with light freckles, messy copper-red curls, thick auburn eyebrows, and bright blue eyes. Dress him in a cream hooded shirt, rust-brown sleeveless scout vest, tan fitted trousers, dark leather ankle boots, a tiny belt pouch, and a short blue neckerchief, with no weapon. Give him a friendly alert expression and a centered front-facing idle stance with separated arms and legs, clear feet contact, a readable silhouette, and animation-ready joints. Use transparent background preferred, crisp 32-bit fantasy RPG pixel-art rendering, no scenery, no readable text, no logo, and no watermark. Keep the entire hair, head, hands, pouch, clothing, boots, and feet fully inside the image with comfortable transparent padding. If transparency is unavailable, use a perfectly flat solid #00ff00 chroma-key background with no shadows, gradients, texture, floor plane, or lighting variation.
```
