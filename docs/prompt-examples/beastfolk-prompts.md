# Beastfolk Pixel-Art Prompt Examples

作成日: 2026-07-27

このファイルは、二足歩行の「獣人」向けprompt例をまとめた参照用メモです。
全員を完全な動物頭、口吻、全身の毛皮、爪または蹄を持つ獣人として描き、人間へ耳と尻尾だけを足した外見は使いません。

## 共通方針

- 1枚につき1人の獣人のみ生成する。
- 完全な動物頭、耳、口吻、手、爪または蹄、足先、尻尾まで全身を画像内に収める。
- 全身を毛皮で覆い、二足歩行の中央idle poseとし、animation-readyな手足の分離を保つ。
- 人間の顔、人間の肌、人間の手へ動物耳だけを付けたkemonomimi表現は禁止する。
- 背景は透明を優先し、不可なら完全な単色クロマキー背景を使う。

## Common Negative Prompt

```text
blur, text, watermark, logo, cropped head, cropped ears, cropped muzzle, cropped horns, cropped hands, cropped claws, cropped hooves, cropped feet, cropped tail, cut off body, extra limbs, missing limbs, duplicate character, multiple characters, quadruped, human face, human head, human nose, human skin, human hands, bare skin, kemonomimi, human with animal ears only, costume ears, mask, helmet, scenery, detailed background, floor shadow, photorealistic, 3d render, vector art
```

## Beastfolk Prompts

### 01. Wolf Beastfolk / 狼獣人

```text
Create exactly one character only as a single full-body pixel-art beastfolk asset: a bipedal gray wolf warrior with a complete anatomically wolf head, long canine muzzle, black nose, upright ears, visible fangs, amber eyes, thick neck ruff, fully fur-covered body, clawed paw-hands, digitigrade clawed feet, and a heavy wolf tail. Dress the wolf in a blue-gray sleeveless travel tunic, leather belt and bracers, and dark cloth leg wraps, with no helmet or weapon. This must be a true animal-headed beastfolk, not a human with animal ears or a tail; show no human face, skin, hair, hands, or plantigrade human feet. Use a centered front-facing bipedal idle stance with separated limbs, clear feet contact, a readable silhouette, and animation-ready joints. Use transparent background preferred, crisp 32-bit fantasy RPG pixel-art rendering, no scenery, text, logo, or watermark. Keep all ears, muzzle, claws, feet, and tail inside the image with transparent padding. If transparency is unavailable, use a perfectly flat solid #00ff00 chroma-key background with no shadows, gradients, texture, floor plane, or lighting variation.
```
